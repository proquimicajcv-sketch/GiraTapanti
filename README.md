# GiraTapanti

App web para identificación rápida de organismos durante la gira a Tapantí.

## Qué incluye

- Catálogo base de organismos (anfibios, reptiles, aves, mamíferos e insectos).
- Búsqueda por nombre común/científico.
- Filtros por grupo, hábitat y actividad.
- Vista de detalle para apoyo en campo.
- Registro local de avistamientos (guardado en el navegador).
- Diseño responsivo para uso en celular.

## Uso

1. Descarga/clona el repositorio.
2. Abre `index.html` en el navegador.
3. Para mejor experiencia móvil, abre la app desde un servidor local simple (por ejemplo Live Server en VS Code).
