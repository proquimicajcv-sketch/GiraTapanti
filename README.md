# GiraTapanti

Aplicación web estática para la curación de fichas de especies observadas en la gira a Tapantí.

## Qué incluye
- Catálogo visual de especies.
- Filtros por búsqueda, familia y estado.
- Edición de URL pública de la imagen de referencia.
- Persistencia local por especie en `localStorage`.
- Tarjetas con metadatos científicos y notas descriptivas.

## Cómo usarla
1. Abre `index.html` en un navegador moderno.
2. Filtra las especies por familia, estado o texto.
3. Edita la URL pública de una imagen y pulsa **Guardar**.
4. Usa **Abrir imagen** para revisar el enlace guardado.

## Publicación en GitHub Pages
Si publicas este repositorio en GitHub Pages desde la rama `main` y la raíz (`/root`), el sitio quedará disponible como una app estática.
